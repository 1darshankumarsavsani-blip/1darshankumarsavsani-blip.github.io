# Darshankumar Savsani: portfolio website

Personal portfolio of Darshankumar Savsani (Diploma in Computer Engineering, Rajkot), in English and Gujarati.

**Live:** https://1darshankumarsavsani-blip.github.io/

## Editions

- Main (light, coral): [/](https://1darshankumarsavsani-blip.github.io/)
- Dark edition: [/dark/](https://1darshankumarsavsani-blip.github.io/dark/)
- Mono edition (dark violet, animated): [/mono/](https://1darshankumarsavsani-blip.github.io/mono/)

## What is inside

- About, skills, projects (Student Planner, Khata Book, Vishwas, File Manager and more), and contact links
- English / Gujarati toggle
- Responsive layout for phone and PC; `robots.txt`, `sitemap.xml` and a custom 404 page

## Tech stack

Plain HTML, CSS and JavaScript. No framework and no build step. Hosted on GitHub Pages.

## Structure

```text
index.html        main portfolio
dark/ mono/       optional editions
assets/           photo and background
404.html          not-found page
```
